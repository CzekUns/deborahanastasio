# Video Deborah Anastasio

Questa cartella è la destinazione consigliata per i video MP4/WebM del prototipo Instagram/TikTok.

- Carica qui i file reali (per esempio `deborah-01-amirante-atelier.mp4`).
- La demo scopre automaticamente gli MP4/WebM presenti sul branch `main`, anche se si trovano in altre cartelle.
- Gli stessi filmati vengono temporaneamente ripetuti su Instagram e TikTok, come concordato.
- Instagram: feed e post 4:5 con player video; TikTok: Home verticale a schermo pieno.
- Le **copertine sono indipendenti dai video**: non è necessario alterare i filmati per cambiarle.
- Quando arrivano le copertine definitive, salvarle nel repository e aggiungere nel file `assets/video-covers.json` una voce `"deborah_media/nome-video.mp4": "assets/copertine/nome-copertina.webp"`.
- Se un filmato non è ancora disponibile sul branch `main`, viene mantenuta l'anteprima esistente senza inventare contenuti video.
- La qualità dei filmati dipende dai file originali: consigliati H.264/AAC in MP4 con faststart per compatibilità mobile.

Al 18 novembre 2026, durante l'ultima verifica, nessun MP4/WebM risultava ancora pubblicato nella repository `CzekUns/deborahanastasio`. La preparazione dei file nell'altra chat non equivale al loro caricamento su GitHub.
